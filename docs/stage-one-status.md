# 第一阶段进度

## 版本

0.1.0-alpha.2，本地开发版本，尚未发布 GitHub。图标和版式继续留空，等待 Figma 交接。

## 已实现

- Core、Windows 适配器、CLI、IPC 和一次性 Broker 拆分。
- 严格型号匹配、通用监控、ThinkBook 风扇只读接口、华硕与机械革命品牌发现。
- 命名管道的用户 ACL、远端网络身份拒绝、双向进程 ID 核对、固定操作白名单、协议长度与版本校验。

- 字段白名单诊断 ZIP、托盘与刷新间隔偏好迁移、GitHub 反馈模板和 CI。

## 实机验证

2026-09-15，LENOVO / 21R0 / ThinkBook 16p G6 IAX / R2CN57WW：普通权限下正确读取内存、电量、亮度，风扇返回 ACCESS_DENIED；使用显式 UAC 后读取双风扇 2500 / 2300 RPM，错误列表为空。调用完成后没有遗留 Broker 进程。未进行风扇写入或调整原程序配置。
