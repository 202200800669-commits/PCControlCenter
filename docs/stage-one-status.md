# 第一阶段进度

## 当前版本

0.1.0-alpha.13，本地开发版本，尚未上传 GitHub。包含普通权限 WPF 桌面客户端、CLI 与受控 Broker。

## 已完成

- Core、适配器、CLI、IPC 和一次性 Broker 分离。
- 华硕与机械革命品牌发现、通用监控、ThinkBook 精确身份匹配与风扇读取。
- 明确请求后 UAC 提权，命名管道用户 ACL、网络身份拒绝、双向进程核对、消息限制。
- 参考机的手动/全速限时试运行与恢复自动命令，独立工作进程负责时限与前端断连后的恢复路径。
- 脱敏诊断、非硬件偏好迁移、本地 Git、CI 与反馈模板。

## 实机验证

2026-09-15，ThinkBook 16p G6 IAX / 21R0 / R2CN57WW：

| 场景 | 结果 |
| --- | --- |
| 普通权限监控 | 型号、内存、电量、亮度正常；风扇接口拒绝访问 |
| 显式 UAC 读取 | 双风扇 2500 / 2300 RPM，无错误 |
| 恢复自动 | 恢复命令无异常，全速开关读回为关 |
| 12 秒手动试运行 | 目标 3500 / 4500，观测 3500 / 4600 RPM，在 250 RPM 容差内 |
| 8 秒全速试运行 | 观测 5400 / 5400 RPM，随后执行恢复路径 |
| 强制结束前端 | Broker 约 6.6 秒后退出；后续读取 3200 / 4200 RPM；原前端已结束，未接收到恢复回执 |

恢复回执 AUTO_COMMANDS_SENT_OVERRIDE_OFF 仅表示发送命令无异常并读回全速关闭。固件未提供独立的自动/手动目标状态，不能把 RPM 降低当成完整恢复证明。故障、系统崩溃、多个工具争用的全面验证尚未完成。

构建零警告、零错误。147 项模拟与本地 IPC 断言通过；另有打包清单错误哈希、越界路径与重复条目三项拒绝检查、12 项打包后 CLI 检查。不等同于独立安全审计或跨品牌实测。

## 后续工作

补充恢复观测、能源特性（充电/键盘）写入迁移、配置与界面连接、来源及许可证确认、发布签名与安装验证。持续控制、温控曲线和正式界面仍未完成；旧版程序保留原位。

已增加故障注入测试，覆盖部分写入失败、逐路恢复失败、错误型号零写入和 stdin 断连后的 finally 路径。新增系统、主板、CPU 与显卡驱动诊断字段；全部为本地收集，不自动上传。

本机 Windows PowerShell 5 的显卡 CIM 枚举失败，已改用只读注册表获取已安装的显示驱动列表，来源标记为 InstalledDriverRegistry，不将其等同于当前活动显卡。

性能模式已完成只读检测，本机观测 ITS 模式 0。反馈包检查器已在本机完成导出与导入验证。配置核心已加入原子替换、版本冲突检查、备份与显式恢复；尚未接入界面。打包脚本自动核对文件清单，CI 加入自包含打包与 CLI 启动检查；GitHub 远程尚未运行这些检查。

连续只读监控已加入 Core 异步流与 `watch` 命令，支持取消与重启，避免慢设备或慢界面造成采样堆积。

- alpha.7：本机连续监控输出两条有效样本。升级 .NET 10 后的两次 UAC 读取被取消，诊断包记录 ELEVATION_CANCELLED。
