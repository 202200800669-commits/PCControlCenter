# 连续监控

`pc-control.exe watch 3` 每次完成读取并交付结果后等待 3 秒，再开始下一次。接受 1–30 秒，Ctrl+C 结束。输出为每行一个 JSON 对象，沿用诊断 schema 2，方便后续界面读取。

监控不发起 UAC。普通账户无法读取风扇时，仍输出对应的不可用状态，不用 0 代替失败，也不自动尝试提权。未知品牌仍走通用只读适配器。

Core 的 `MonitorSession.WatchAsync` 使用异步流：第一条结果立即读取；慢界面或慢硬件不会堆积定时任务；单会话拒绝同时启动两个消费者；取消等待或释放枚举器后可重启。消费者收到身份变化异常时应停止展示旧设备数据并重新识别。

当前 CLI 持续显示所有采样，不写监控日志，不自动上传。刷新偏好与 GUI 的连接、图表、托盘生命周期仍待后续界面实现。
