# 下一轮开发入口

当前为 alpha.9。先阅读阶段进度、架构和发布门槛，再运行 scripts/verify.ps1。本机便携 .NET 10 SDK 在 local/dotnet10；旧 ThinkBook 控制中心保留原位，不要以新 CLI 覆盖它。图标与布局等待负责人提供 Figma。

## 优先处理

1. 对最新版进行一次同账户 UAC 读取回归，并检查诊断中的 issueCodes。导出成功不能当作风扇读取成功；此前两次新版读取因 UAC 取消而未完成。
2. 修正全局互斥锁后，验证受控风扇试运行与恢复。记录程序版本、固件、请求参数、实际 RPM、恢复回执。固定样机仅为 ThinkBook 16p G6 IAX / 21R0 / R2CN57WW。
3. 性能模式目前只读。迁移写入前核对模式接口及先前状态能否恢复，避免与风扇会话争用。不能把旧原型支持所有功能直接移植为新软件的兼容声明。
4. 等待界面设计后连接 MonitorSession、PreferenceStore、LatestControlQueue。请求合并层没有开放真实持续写入，风扇试运行仍为独立 FanTrial。
5. 核对接口来源和许可证、安装目录权限与签名，再配置 GitHub 远程和发布试点包。CI 已配置但尚未在远程运行。

## 本地证据

local 目录包含旧版风扇试运行、断连记录、新版监控样本、反馈包、打包与源码检查记录。该目录被忽略，不能作为原始附件直接提交到公开仓库。引用结论时区分此前 alpha 的实机结果、当前版本模拟结果和当前版本实机结果。

跨品牌写入尚未实现。华硕和机械革命当前只做品牌发现与通用诊断；新型号报告导入固定为未验证，不会修改控制白名单。
