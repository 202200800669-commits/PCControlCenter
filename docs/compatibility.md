# 当前兼容范围

此表适用于 0.1.0-alpha.15 社区试点版。代码实现、模拟测试、旧版本实机记录和当前版本完整实机验证是不同的证据，不应混同。

| 品牌 / 设备 | 身份要求 | 当前能力 | 专用写入 |
| --- | --- | --- | --- |
| Lenovo ThinkBook 16p G6 IAX | LENOVO / 21R0 / R2CN57WW | 通用监控；专用模式、能源与风扇读取；风扇读取可请求 UAC | 白名单上的持续手动风扇、模式和能源操作；桌面会话授权一次 |
| ASUS / ASUSTeK | 品牌识别 | 通用监控、只读接口探测、反馈导出 | 未开放 |
| MECHREVO | 品牌识别 | 通用监控、只读接口探测、反馈导出 | 未开放 |
| 其他或未识别 | 无 | 系统与驱动提供的通用监控 | 未开放 |

机械革命部分设备可能报告代工厂名称，从而进入通用适配器。相同品牌、代工厂、相似型号或未经验证的 BIOS 不能用于自动开放写入。

当前分发面向 Windows x64。没有电池、多个亮度接口、驱动缺失、权限不足或独显休眠可能导致部分读数不可用。桌面总览显示首个可用 NVIDIA 遥测设备，报告与底层探测保留多设备通道；AMD/Intel GPU 专用遥测尚未实现。

alpha.15 已在上述参考机型和 BIOS 上完成一次 UAC 授权后的背光切换、独立回读及原值恢复；同一连接连续控制双风扇超过 30 秒，中途分别调整至 4900 / 5100 RPM，实测读数跟随目标；停止后确认自动控制指令已发送且手动覆盖关闭，并继续使用同一授权执行能源操作。充电与夜间慢充仅验证保持原值的请求和回读，未在本次测试切换电池模式。掉线、心跳超时、非法目标及恢复路径由模拟硬件自动化测试覆盖。

这些结果不等于其他机型或所有控制路径的实机认证。欢迎先提交只读诊断，再安排明确机型、BIOS 和驱动组合的试点。
