# 兼容记录

本表描述新项目，不把旧版验证直接算作新架构验证。

| 品牌和设备 | 身份要求 | 新项目状态 | 控制写入 |
| --- | --- | --- | --- |
| 联想 ThinkBook 16p G6 IAX | LENOVO / 21R0 / R2CN57WW | 通用监控；双风扇读取视接口权限而定 | 禁用 |
| 华硕 | ASUS 或 ASUSTeK COMPUTER INC. | 品牌发现与通用监控 | 未适配 |
| 机械革命 | MECHREVO | 品牌发现与通用监控 | 未适配 |
| 其他或身份不明 | 无 | 通用监控 | 禁用 |

机械革命的部分设备可能报告代工厂名称，当前会落入通用监控；不能按“同代工厂”自动启用控制。BIOS 或型号变化后，ThinkBook 专用读取也会关闭。

通用监控读取失败可由接口不存在、权限、多个设备歧义等造成。首期不假设电池存在，不选择多个电池中的任意一个，也不选择多个活动亮度接口中的任意一个。
