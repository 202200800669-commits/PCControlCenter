# alpha.17 响应优化

普通监控刷新不再重复运行完整设备清单扫描，也不再重复调用显卡遥测。完整扫描保留在启动和用户主动生成反馈时。电池循环次数每分钟读取一次，电量仍按监控周期更新。

驱动读取与外部进程启动移到后台；性能模式和能源设置收到确认回执后立即结束等待，不再额外等待遥测。刷新开始后发生过硬件操作时，旧读数不会覆盖新回执。

页面仅在可见时更新，并将一批属性通知合并成一次控件刷新。窗口隐藏或最小化时暂停普通遥测，重新显示后刷新；风扇控制心跳、授权连接与恢复机制独立运行，不受影响。

三种彩色主题继续使用四层流动色彩。渐变图层缓存后只动画变换和透明度，避免逐帧重绘渐变颜色。黑白主题与关闭动效选项保持不变。

## 本机对照

ThinkBook 16p G6 IAX，Windows x64，相同 WPF 离屏窗口、实际只读遥测，连续执行五次刷新：

| 项目 | alpha.16 | alpha.17 候选构建 |
| --- | ---: | ---: |
| 刷新耗时（毫秒） | 3383 / 2594 / 2576 / 2696 / 2604 | 542 / 61 / 62 / 63 / 67 |
| 中位耗时 | 2604 ms | 63 ms |

首次刷新包含电池循环次数查询。该结果衡量遥测任务完成时间，不代表可见窗口帧率，也不代表硬件固件写入速度；其他设备与后台负载可能得到不同结果。没有改变硬件验证、允许范围、UAC 或故障恢复规则。

回归测试覆盖：慢读取不阻塞调用方、重复刷新不积压、控制确认不等待遥测、旧采样不覆盖新设置、完整反馈检测保留、隐藏页面不更新、通知合并以及重新显示后的状态更新。
