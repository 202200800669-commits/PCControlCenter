# 滑块请求合并

`LatestControlQueue` 为未来界面的单个功能提供待执行值合并，默认窗口 150 毫秒。快速拖动时，只保存尚未执行的最新值，被替代的请求明确返回 Cancelled。

已经进入硬件操作的请求不会被新的滑块值打断。关闭队列时取消尚未执行的值，并等待正在执行的操作返回结果。界面应异步等待释放，不阻塞 UI 线程，也不能提前显示硬件恢复成功。

每个队列固定一个 Feature，不会把亮度操作与风扇操作相互替代。执行仍通过 Controller 重新检查型号、权限、验证级别、范围和取消标记。

当前真实适配器没有通过普通数值 Controller 开放持续写入，因此这层不会新增可用的硬件控制权限。参考机限时风扇试运行仍使用独立 FanTrial 和显式 UAC；持续调速、温控曲线与界面接入尚未完成。

模拟测试覆盖连续 100 次更新仅执行最新待处理值、非有限值拒绝、活跃操作不被中断、关闭队列后拒绝提交，以及关闭时等待已开始操作。
